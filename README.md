# Listas de Exercícios em Python

Este repositório reúne as questões práticas desenvolvidas nas listas de
exercícios da disciplina, organizadas de forma a facilitar a
identificação, consulta e execução dos códigos.

## Identificação da atividade

-   **Estudante:** Paulo Augusto dos Reis Oliveira
-   **Curso:** Licenciatura em Ciência da Computação
-   **Semestre:** 3º semestre
-   **Atividade:** Listas de exercícios práticos de programação em
    Python

## Objetivo das listas

As listas têm como objetivo praticar os conteúdos estudados na
disciplina por meio do desenvolvimento de programas em Python, aplicando
os conceitos trabalhados durante as aulas.

## Conteúdos trabalhados

Ao longo das listas foram desenvolvidas questões envolvendo diferentes
conceitos de programação em Python, de acordo com os conteúdos abordados
na disciplina.

## Organização das questões

As questões estão identificadas pelo número da lista e pelo número da
questão, facilitando a localização dos arquivos no repositório.

Exemplos de identificação:

-   `LISTA_01_QUESTÃO_01.py`
-   `LISTA_02_QUESTÃO_01.py`
-   `LISTA_03_QUESTÃO_01.py`

## Orientações para execução dos códigos

Para executar uma questão:

1.  Tenha o Python instalado no computador.
2.  Abra o arquivo `.py` desejado em um editor de código, como o Visual
    Studio Code.
3.  Execute o programa.
4.  Quando solicitado, informe os dados necessários pelo terminal.
